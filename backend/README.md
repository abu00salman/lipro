# Lipro Academy Manager — الخادم (Cloudflare Worker + D1)

الخادم الخلفي للتسجيل ولوحة الإدارة. لا توجد أي تبعيات خارجية: الكود يعمل على Web Crypto وفي Node 22 للاختبارات.

```
backend/
  src/
    coaching.js        المدربون والفرق والحصص والحضور وتقرير الحضور
    store.js           المنتجات والطلبات (التحويل البنكي فقط)
    index.js           توجيه الطلبات، CORS، تحويل الأخطاء
    registrations.js   تسجيل عام (Idempotency)، حالة، إشعار تحويل
    admin.js           دخول + MFA، قوائم بنطاق الفرع، مطابقة التحويلات، تقارير، CSV
    auth.js            PBKDF2، TOTP (RFC 6238)، تشفير الأسرار، الجلسات
    rbac.js            الأدوار والصلاحيات ونطاق الفرع
    validate.js        التحقق من الحقول على الخادم
    ratelimit.js       حدود المحاولات (D1)
    audit.js           سجل التدقيق
    util.js            ردود JSON، ترويسات الأمان، أدوات التشفير
  migrations/0001_init.sql   المخطط الأساسي (المرحلة 0 و1)
  migrations/0002_coaching.sql  المدربون، الفرق، الفئات، الحصص، الحضور (المرحلة 2)
  migrations/0003_store.sql  طلبات المتجر (نفس أعمدة جدول lipro-db الحي)
  seed/demo-data.sql         بيانات خيالية للتطوير المحلي فقط
  scripts/bootstrap-owner.mjs إنشاء أول حساب مالك دون حفظ كلمة المرور
  test/                      57 اختبارًا (منطق + تكامل على SQLite حقيقي)
  wrangler.toml
```

## الأوامر

```bash
npm test                 # تشغيل كل الاختبارات
npm run bootstrap-owner  # يطبع SQL لإنشاء المالك (يقرأ كلمة المرور من البيئة)
```

| GET | `/api/config` يشمل `products` | كتالوج المتجر من الخادم |
| POST | `/api/orders` | طلب متجر. السعر من الكتالوج فقط. الدفع بالتحويل البنكي فقط |
| GET | `/api/orders/:number` | حالة الطلب بلا بيانات اتصال |

مسارات متوقفة عمدًا: `/api/lookup/*` ← `410`. لا توجد أي بوابة دفع إلكتروني: الدفع بالتحويل البنكي فقط، والتواصل عبر واتساب.
مسارات ما زالت على الخادم الحي فقط: `/api/admin/daily`، `/api/daily`، `/api/admin/set`، `/api/admin/set-delivery`، `/api/admin/approve` (طلبات المتجر).

## الأدوار

| الدور | النطاق | ما يستطيع |
|---|---|---|
| owner | كل الفروع | كل شيء، إدارة الحسابات |
| admin | كل الفروع | التسجيلات، اللاعبون، مراجعة الإشعارات، التقارير |
| accountant | كل الفروع | مطابقة التحويلات واعتمادها، التقارير، التصدير |
| branch_manager | فرع واحد | التسجيلات واللاعبون والتصدير في فرعه |
| registration | فرع واحد | التسجيلات واللاعبون في فرعه |
| coach | فرعه وفريقه فقط | يسجّل الحضور لفريقه، ولا يصل لفرق المدربين الآخرين |
| auditor | كل الفروع | قراءة فقط: التسجيلات والمدفوعات والتقارير والتدقيق |
| guardian | — | بوابة ولي الأمر في المرحلة 4؛ لا وصول إداري حاليًا |

الخادم يفرض النطاق: طلب فرع آخر من مستخدم مقيّد يُرجع `403`، وسجل فرع آخر يُرجع `404` كأنه غير موجود.

## الأمن المطبّق

- **المبالغ بالهللة** (أعداد صحيحة). السعر يُقرأ من قاعدة البيانات، ولا يقبل الخادم سعرًا من العميل.
- **Idempotency:** نفس المفتاح ونفس البيانات ← نفس الرقم. نفس المفتاح وبيانات مختلفة ← `409`.
- **ولي الأمر متعدد الأبناء:** جدول `guardians` مفتاحه الجوال. الطلب العام لا يعدّل بيانات ولي أمر موجود.
- **MFA:** TOTP مع منع إعادة استخدام الرمز، وسر التحقق مشفّر بـ AES-GCM.
- **كلمات المرور:** PBKDF2-SHA256 (100,000 تكرار)، قفل بعد 5 محاولات فاشلة لمدة 15 دقيقة.
- **الجلسات:** توكن عشوائي 256 بت، يُخزَّن هاشه فقط، مدة 8 ساعات. لا كوكيز، لذلك لا ينطبق CSRF على الـ API.
- **حدود المحاولات:** تسجيل 10 لكل IP/ساعة، إشعارات تحويل 10/ساعة، بحث الحالة 30/دقيقة، تسجيل الدخول لكل بريد 10 كل 15 دقيقة.
- **التدقيق:** كل إنشاء/اعتماد/رفض/تصدير/دخول يُسجَّل بدون بيانات شخصية خام.
- **CSV:** ترميز UTF-8 مع BOM، وتحييد صيغ الجداول (`=`، `+`، `-`، `@`).
- **ترويسات:** `nosniff`، `X-Frame-Options: DENY`، `Cache-Control: no-store`، CSP صارم على ردود JSON.
- **الحقول:** كل حقل يُتحقق منه على الخادم. الطول الزائد يُرفض ولا يُقص بصمت.

## ما هو خارج هذا الإصدار

- **إيصالات التحويل كصور (R2):** غير مفعّلة. الاعتماد يتم من كشف البنك لا من الصورة.
- **PDF والفواتير وZATCA:** غير مفعّلة. يحتاج قرارًا من المحاسب بشأن نوع الفوترة.
- **المدربون والحضور والجداول والرواتب:** المرحلة 2 و3.
- **بوابة ولي الأمر والمواصلات والبطولات:** المرحلة 4.
- **الاشتراكات والتجديد والتجميد:** لم تُنفّذ بعد. الدفع الحالي يسجّل تسجيلًا لمرة واحدة.
- **تعديل البرامج والأسعار من الواجهة:** غير متاح. الأسعار في جدول `programs`.
- **Rate limit مبني على D1:** تقريبي لكنه كافٍ لهذا الحجم. ليس بديلًا عن WAF في Cloudflare.
- **الاحتفاظ بالبيانات والنسخ الاحتياطي:** يحتاج سياسة من الإدارة (PDPL).
