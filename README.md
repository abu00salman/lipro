# أكاديمية ليبرو الرياضية — الموقع الرسمي

موقع أكاديمية ليبرو الرياضية: أكاديمية كرة قدم مرخصة من وزارة الرياضة،
٨ فروع في منطقة جازان ومدينة خميس مشيط.

**الرابط:** https://abu00salman.github.io/lipro/

## المحتوى

| الملف | الوصف |
|---|---|
| `index.html` | الموقع كاملًا — HTML و CSS و JavaScript والشعار في ملف واحد |
| `logo-lipro.png` | شعار الأكاديمية بخلفية شفافة |
| `.nojekyll` | يمنع GitHub من معالجة الملفات قبل النشر |

الموقع لا يعتمد على أي مكتبة خارجية عدا خطوط Google Fonts، ويعمل بفتح
`index.html` مباشرة في المتصفح بدون خادم.

## المميزات

- لوحة **«التدريب اليوم في»** تقرأ اليوم بتوقيت الرياض وتؤشر تلقائيًا على الفروع المتدربة
- بطاقات الفروع الثمانية مع الأيام والأوقات والملاعب وروابط الخرائط
- جدول الرسوم شاملًا عرض الشهرين وتسعيرة فرع جيزان
- نموذج تسجيل يفتح واتساب برسالة جاهزة (بدون خادم)
- تصميم عربي RTL ومتجاوب مع الجوال

## التعديل

كل بيانات الفروع في مصفوفة `BRANCHES` داخل `index.html`.
لتغيير موعد أو ملعب، عدّل السطر الخاص بالفرع فقط:

```js
{name:"ليبرو جيزان", city:"محافظة جيزان", group:"A",
 time:"٥:٠٠ – ٧:٣٠ م", venue:"ملعب يارا — حي المعبوج", map:"https://..."}
```

`group:"A"` = السبت والاثنين والأربعاء · `group:"B"` = الأحد والثلاثاء والخميس
